# Caja Fuerte Nº 7

Una página estática: escribes una frase, se sella dentro de un link, y quien lo abre
tiene que descifrar una combinación de 3 dígitos para leerla.

La caja responde dial por dial: correcto / más alto / más bajo. Se gana deduciendo.

La frase viaja codificada en el `#hash` del link — no se guarda en ningún servidor.

Publicado con GitHub Pages.
